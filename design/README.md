## 设计约定

- 侧栏参考用户提供的截图：圆角内嵌面、轻量整行选中背景和分组标签。保留品牌、工作区导航与当前目标，不展示副标题、设置入口或底部文案。使用 macOS 左上角交通灯，不增加关闭或返回按钮。亮色版侧栏采用浅灰材质。
- 亮色：窗口 `#FFFFFF`，最外层使用 1px 内描边 `#BAC5CC` 标示边界；侧栏 `#F7F7F7`，使用 1px 内描边 `#D6D8DA` 及柔和投影；信息面板 `#F7F8F9` 主要通过填充对比区分，不额外叠加边线。按钮和选中项优先使用填充色，不使用 2px 粗边。侧栏选中为 `#E8E9EA`。深蓝灰正文，深绿色表示正常，深琥珀色表示失败或保护状态，蓝色用于操作和配置选择，提示背景使用对应的浅色。
- 亮色圆角保持克制但有层级：信息面板约 14px，配置卡片约 12px，按钮约 9px，侧栏约 12px；避免使用胶囊形容器，同时让卡片和控件比直角界面更柔和。
- 暗色对照：窗口 `#252B2F`、侧栏 `#353E43`、信息面板 `#333D43`、侧栏选中 `#536067`。
- 字体：界面采用系统字体；规则匹配值采用 SF Mono。主标题 28，分区标题 17，主要内容 14，辅助信息 11–13。
- 概览只展示信息，不放流量趋势图、启动或停止核心等快捷操作。
- 侧栏只保留“配置”入口；配置页内统一管理配置来源、选择基础配置、维护自定义变更及展示最终生效结果。本地配置与远程订阅使用独立卡片分组；远程订阅卡片展示剩余流量、总量、进度、更新时间和到期时间，额度不可用时显示明确的空值状态，更新失败时保留上一版有效版本。
- 配置卡片网格建议以内容区宽度计算列数：列间距 16px，每列目标宽度 280–320px，列数取能容纳的最大数量，卡片等宽且不超过 320px；卡片不足一行时左对齐，剩余空间留空。内容区不足 280px 时单列随空间收缩。当前 930px 内容区可容纳三列，设计稿中的卡片约 299px；这是布局规格，Sketch 静态画板本身不会自动响应窗口变化。
- 配置页三个 Tab 的顺序固定为「生效的配置 / 自定义配置 / 选择的配置」；选择和管理基础配置共用同一组卡片。
- 当前基础配置直接在卡片上使用 1px 绿色细边框和带对勾的文字标记，其他卡片提供“应用”入口；不再设置重复的顶部状态横条。切换失败时保留原基础配置标记并显示失败原因，失败交互尚待设计细化。
- 自定义配置优先；变更、切换基础配置或远程更新后自动生成并应用。失败时继续使用上一版有效结果，并说明原因和恢复方式。

## 本轮评审边界

本轮亮色稿用于评审合并后的页面结构、视觉和关键状态；新增、编辑、重命名、删除确认等弹层、完整可点击原型、完整的空状态和窗口缩放细节尚未细化。菜单栏弹出面板中的新入口也未在本稿重绘。

窗口外层为白色，侧栏及信息面板采用浅灰色，并增加细边框以便在 Sketch 画布上辨识；此稿不能替代运行时交互检查。

本轮未修改应用源码、未运行应用功能测试，也未改变看板需求的执行状态。原有 `ClashBar-内部看板.sketch` 保留，当前成果存放在此目录。
