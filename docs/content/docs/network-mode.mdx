在配置可用、节点测通之后，再打开网络接管。ClashBar 提供**系统代理**和 **TUN** 两种方式：建议先用系统代理；只有需要透明代理、或要覆盖不遵循系统代理的应用流量时，再考虑 TUN。

节点与运行态观察见 [日常使用](/docs/daily-use)；端口与绕过列表见 [设置与维护](/docs/settings)。

## 系统代理

在“快捷操作”中点击“系统代理”即可开启或关闭 macOS 系统代理。ClashBar 会使用当前配置中的 HTTP、SOCKS 或混合端口设置。

系统代理使用一个需要管理员权限的特权 Helper。第一次使用前，请在“设置”的“系统代理 Helper”区域检查版本并点击“安装 Helper”；macOS 会要求管理员密码。Helper 会安装到 `/Library/PrivilegedHelperTools/com.clashbar.helper`，只负责修改 macOS 系统代理，mihomo 内核负责实际网络转发。之后更新 ClashBar 时，设置页会显示已安装版本与当前版本，只有 Helper 版本变化时才需要再次授权。未安装或版本过旧时，系统代理开关只会提示前往设置更新，不会在开关操作中隐式安装。

### 代理绕过

在“设置”的“代理绕过”区域可添加不应走系统代理的主机、域名、CIDR 或 `<local>` 条目。这些内容会写入 macOS 的代理绕过列表，并会在重新应用系统代理时保留。

如果当前控制的是远程 Mihomo，请先确认远程地址从本机可达；系统代理会指向该远程端点。

## TUN 模式

TUN 允许 Mihomo 在更低层处理网络流量。开启时 ClashBar 会请求管理员授权，并要求本地 `mihomo` 内核具有 root 与 setuid 权限。

开启步骤：

1. 确认本地内核位于 `~/config/clashbar/core/mihomo` 且可执行。
2. 在“快捷操作”或“设置”中开启 TUN 模式。
3. 在 macOS 授权提示中输入管理员凭据。
4. ClashBar 重启内核并验证 TUN 状态。

> TUN 仅作用于本地内核。连接远程机器时，相关本地设置不可修改。

## 使用建议

- 普通浏览器和常见应用：优先使用系统代理。
- 某些不遵循系统代理的应用或需要透明代理：使用 TUN。
- 遇到网络异常：先关闭 TUN 和系统代理之一，避免同时排查多个变量。

代理端口、绕过列表编辑与维护操作见 [设置与维护](/docs/settings)。远程 External Controller 见 [远程机器](/docs/remote-machine)。能力总表见 [功能总览](/docs/features)。
